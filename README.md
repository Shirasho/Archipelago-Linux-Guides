This repository contains instructions for getting Archipelago worlds to work properly when they don't have first-party Linux support or lack proper Linux installation instructions.

Pull requests are highly appreciated and encouraged for the following situations:
* A guide does not exist for a specific game.
* You are using a Linux distro not included in the **Tested Linux Flavors** within a guide and have verified the instructions work on your distro.
* The instructions do not work for you out of the box and you had to install additional dependencies.
* You want to add clarity to existing instructions.

If you are adding a new guide please assume that the reader just installed Linux for the first time 5 minutes before reading the guide. If a command needs to be run you should write out the entire command and explain what every part of that command does. The exception is for Wine-related operations and Wine prefixes - users are expected to understand what prefixes are and where to find them within Steam.
